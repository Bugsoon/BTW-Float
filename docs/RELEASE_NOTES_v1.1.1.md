## BTW-Float v1.1.1

面向 Windows 11 的轻量 `/btw` 风格桌面 AI 悬浮球助手。随手呼出、问完即走、关闭自动清空。

### 下载

| 文件 | 说明 |
| --- | --- |
| `BTW-Float_1.1.1_x64-setup.exe` | Windows 64 位安装包（NSIS），双击安装，自动创建开始菜单与桌面快捷方式，支持卸载 |

### 本次更新（v1.1.1）

- **流式回答阅读体验优化**
  - 生成长回答或连续追问时，自动将当前回答的首行对齐到滚动区上边界并停住，后续内容自然向下延展，不再把首行顶出视野、无需反复向上翻找开头。
  - 生成过程中随时支持用户自由上滑、下滑、拖动滚动条或划选文字，手动介入后立即交出滚动控制权，不再被流式输出强行拉回底部。

### 系统要求

- Windows 11（x64）
- WebView2 Runtime（Windows 11 默认自带，通常无需单独安装）
- 需要自备大模型 API Key（BYOK，本项目不含任何内置额度）

### 安装提示

安装包未做代码签名，Windows SmartScreen 可能提示「未知发布者」。点击 **更多信息 → 仍要运行** 即可正常安装。
