## BTW-Float v1.1.2

面向 Windows 11 的轻量 `/btw` 风格桌面 AI 悬浮球助手。随手呼出、问完即走、关闭自动清空。

### 下载

| 文件 | 说明 |
| --- | --- |
| `BTW-Float_1.1.2_x64-setup.exe` | Windows 64 位安装包（NSIS），双击安装，自动创建开始菜单与桌面快捷方式，支持卸载 |

### 本次更新（v1.1.2）

- **后台常驻与单实例体验**
  - 窗口采用 Win32 工具窗口样式归入后台进程（隐藏任务栏与 Alt+Tab 残留）、阻止意外关闭退出、重复启动自动唤醒已有实例，同时保持桌面悬浮球默认显示并支持在托盘与设置中自由开关。
- **系统托盘交互与浅色悬浮球图标**
  - 精简托盘悬停提示为 `BTW-Float`，左键/右键均直接打开菜单；新增与悬浮球风格一致的 `64×64` 浅色天青磨砂球图标（`tray-light.png`），兼容 Atrium 等第三方玻璃任务栏，避免被误判为白色单色图标而自动变黑。
- **全端统一浅色视觉**
  - 悬浮球、磨砂胶囊与设置窗口统一固定为浅色主题，移除深浅色动态切换逻辑。

### 系统要求

- Windows 11（x64）
- WebView2 Runtime（Windows 11 默认自带，通常无需单独安装）
- 需要自备大模型 API Key（BYOK，本项目不含任何内置额度）

### 安装提示

安装包未做代码签名，Windows SmartScreen 可能提示「未知发布者」。点击 **更多信息 → 仍要运行** 即可正常安装。
