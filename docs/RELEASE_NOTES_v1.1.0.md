## BTW-Float v1.1.0

面向 Windows 11 的轻量 `/btw` 风格桌面 AI 悬浮球助手。随手呼出、问完即走、关闭自动清空。

### 下载

| 文件 | 说明 |
| --- | --- |
| `BTW-Float_1.1.0_x64-setup.exe` | Windows 64 位安装包（NSIS），双击安装，自动创建开始菜单与桌面快捷方式，支持卸载 |

### 本次更新（v1.1.0）

- **悬浮球贴边半隐藏正式实现**
  - 将悬浮球拖至屏幕左/右边缘时自动吸附并收起大半（仅露出约 18px 边缘），鼠标移过去平滑滑出，移开后自动缩回。
  - 兼容高 DPI 缩放与多显示器：外侧边缘采用原生 `SetWindowPos` 贴边收起，双屏接缝处自动切换容器裁剪防止溢出到相邻屏幕。
  - 启动时自动恢复贴边状态，设置中切换开关即时生效。
- **指定软件完全禁用（游戏免打扰模式）**
  - 设置页新增「在指定软件里完全禁用 BTW-Float（游戏免打扰）」列表：切换到对应前台应用时自动隐藏悬浮球与悬浮窗，并临时注销全部系统级全局快捷键与鼠标侧键（彻底透传给游戏、不吞键）；切回其他软件后无焦点自动恢复。
- **进程选择器支持实时模糊搜索**
  - 「完全禁用」与「仅禁用鼠标侧键」的进程添加抽屉均支持输入关键词实时模糊匹配当前运行进程（按完全/前缀/子串/模糊子序列排序），并支持一键刷新运行中进程列表与手动录入进程名（忽略大小写与 `.exe` 后缀）。

### 系统要求

- Windows 11（x64）
- WebView2 Runtime（Windows 11 默认自带，通常无需单独安装）
- 需要自备大模型 API Key（BYOK，本项目不含任何内置额度）

### 安装提示

安装包未做代码签名，Windows SmartScreen 可能提示「未知发布者」。点击 **更多信息 → 仍要运行** 即可正常安装。
